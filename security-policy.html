Security Policy

For Bizappe Apps on the Atlassian Marketplace

Security Policy

Last Updated: Jan 10, 2026

Overview

Bizappe is committed to protecting customer data and maintaining the highest standards of security for all applications and services provided through the Atlassian Marketplace.

This Security Policy describes the administrative, technical, and organizational measures implemented by Bizappe to safeguard customer data and ensure secure operation of our services.

1. Security Program

Bizappe maintains a comprehensive security program designed to:

  • Protect customer data
  • Ensure system integrity
  • Prevent unauthorized access
  • Comply with applicable data protection regulations
  • Follow Atlassian Marketplace security requirements

Our security program includes:

  • Access control policies
  • Vulnerability management
  • Secure development practices
  • Monitoring and logging
  • Incident response procedures
  • Regular security reviews

2. Data Protection Principles

Bizappe processes data according to the following principles:

  • Least privilege access
  • Data minimization
  • Secure data transmission
  • Encryption where appropriate
  • Strong authentication
  • Continuous monitoring

Customer data is only accessed when necessary to provide the service or to resolve support requests.

3. Infrastructure Security

Bizappe services are hosted using secure cloud infrastructure that provides:

  • Physical security controls
  • Redundancy and availability
  • Network isolation
  • Automated security updates
  • DDoS protection
  • Infrastructure monitoring

Access to production systems is restricted to authorized personnel and protected using strong authentication mechanisms.

4. Data Encryption

Bizappe protects data using industry-standard encryption methods.

Encryption in Transit

All data transmitted between users, Atlassian services, and Bizappe infrastructure is encrypted using TLS (Transport Layer Security).

Encryption at Rest

Where applicable, stored data is protected using encryption mechanisms provided by the cloud infrastructure provider.

5. Access Control

Access to systems and customer data is restricted using strict access control policies.

Security controls include:

  • Role-based access control (RBAC)
  • Least privilege principles
  • Secure authentication mechanisms
  • Logging of administrative access
  • Periodic access reviews

Only authorized personnel with a legitimate business need may access production environments.

6. Secure Development Practices

Bizappe follows secure software development practices to reduce vulnerabilities.

Our development process includes:

  • Secure coding standards
  • Code reviews
  • Dependency vulnerability scanning
  • Automated security testing
  • Regular patch management

Security considerations are integrated into all stages of the development lifecycle.

7. Vulnerability Management

Bizappe actively monitors and addresses security vulnerabilities. This includes:

  • Regular dependency scanning
  • Monitoring security advisories
  • Applying security patches promptly
  • Periodic security assessments

Critical vulnerabilities are prioritized and remediated as quickly as possible.

8. Logging and Monitoring

Bizappe maintains monitoring systems to detect suspicious activity and security incidents.

Monitoring includes:

  • Infrastructure monitoring
  • Application error monitoring
  • Audit logging of administrative actions
  • Anomaly detection where applicable

Logs are reviewed when investigating incidents or system issues.

9. Incident Response

Bizappe maintains an incident response process for handling security incidents.

The process includes:

  • Detection and analysis
  • Containment and mitigation
  • Investigation
  • Customer notification where required
  • Remediation and prevention

In the event of a confirmed data breach affecting customer data, Bizappe will notify affected customers without undue delay in accordance with applicable laws.

10. Subprocessors

Bizappe may use trusted third-party service providers (subprocessors) to operate the service.

These providers may include:

  • Cloud hosting providers
  • Monitoring tools
  • Infrastructure services

All subprocessors are carefully selected and required to maintain appropriate security standards.

11. Data Retention and Deletion

Bizappe retains customer data only for as long as necessary to provide the service and comply with legal obligations.

When customer data is no longer required:

  • It is securely deleted, or
  • Anonymized where appropriate

Customers may request deletion of their data in accordance with applicable data protection laws.

12. Employee Security

All employees and contractors are required to follow security best practices.

Security measures include:

  • Confidentiality agreements
  • Restricted access to systems
  • Security awareness practices
  • Controlled access to production environments

Access rights are revoked immediately upon termination of employment.

13. Compliance and Privacy

Bizappe is committed to complying with applicable data protection regulations including:

  • General Data Protection Regulation (GDPR)
  • Applicable national privacy laws

Bizappe provides a Data Processing Agreement (DPA) for customers where required.

14. Atlassian Ecosystem Security

Bizappe applications integrate with Atlassian products using secure APIs and follow Atlassian Marketplace security requirements.

Applications operate within the permission scope granted by the user and only access data necessary to provide the intended functionality.

15. Responsible Disclosure

Bizappe encourages responsible disclosure of security vulnerabilities.

If you believe you have discovered a security vulnerability in our services, please report it to: security@bizappe.com

Please include:

  • Description of the vulnerability
  • Steps to reproduce
  • Potential impact

Bizappe will investigate all reports and respond as quickly as possible.

16. Updates to This Policy

Bizappe may update this Security Policy from time to time to reflect changes in our practices or regulatory requirements.

The most current version will always be available on our website.
